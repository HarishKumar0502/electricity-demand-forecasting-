🚀 Project Overview

Electricity Demand Forecasting predicts future power consumption using historical and environmental data.
It helps optimize energy usage, improve grid stability, and support smart energy systems.

🔹 RMSE (Baseline): 195

🔹 RMSE (With Lag Features): Improved learning

🔹 RMSE (Final with UI Enhancements): 250
